## B2：三个高权重抽取器并行

### 病害抽取（30分，最高优先级）

- [ ] 定位病害表和跨页续表。
- [ ] 恢复合并单元格、重复表头、同序号多行。
- [ ] 按“一条具体病害观察”输出 `DefectObservation`。
- [ ] 每条记录绑定 `SourceAnchor`。
- [ ] 优先保证行召回与原文完整，后做类型归一化。

### 概要/评分抽取（20分）

- [ ] 桥梁名称、报告日期候选。
- [ ] 总体、上部、下部、桥面系评分与等级。
- [ ] 建立来源优先级和候选冲突记录。
- [ ] 禁止用 LLM 猜测数字。

### 建议抽取（20分）

- [ ] 表格和处理建议章节双路抽取。
- [ ] 建议内容、部位、类别、序号。
- [ ] 类别不确定时输出质量标记，不强行补值。

### 评测与错题本

- [ ] 保留严格官方代理分。
- [ ] 增加字段级诊断分、病害规模分桶、模板簇分桶。
- [ ] 每次合并记录 commit、配置、分项得分和失败样本。

## B3：端到端交付

```text
原始 DOC
→ DOCX
→ DocumentModel
→ route_sections
→ 三个抽取器
→ prediction.json
→ DOCX
→ 最终 DOC
→ 文件名/数量校验
→ tar.gz
```

门禁：输入输出数量一致、失败显式记录、Gold渲染回环100、最终包根目录只含对应 `.doc`。
