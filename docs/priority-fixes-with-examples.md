```
C2: 裂缝/开裂：报告已记录该类病害，可能与构件受力、材料收缩或温度变化有关，
    报告未明确单一主因。
C3: 露筋锈蚀：混凝土保护层破损或剥落使钢筋暴露并受水汽侵蚀，报告未明确具体主因。
C4: 渗水泛碱：报告记录水迹或泛碱病害，说明水分进入或排水、防水条件存在问题，
    具体主因未明确。
C5: 铺装/伸缩缝破损：报告记录铺装或伸缩缝破损，可能与车辆荷载、温度变形及长期使用有关，
```

## 提分点 3：risk_points "病害+后果"模板

### 官方期望（赛题一文档"主要风险点"示例）

```
左幅空心板大面积露筋锈蚀、局部蜂窝麻面破损，右幅空心板存在纵向裂缝，长期渗水会加速钢筋锈蚀，
削弱主梁承载力； 全桥支座普遍开裂、剪切变形、垫板锈蚀，持续劣化会改变梁体受力；

```

格式：`{病害描述}，{后果}；{病害描述}，{后果}；…`——**每条 = 病害事实 + 后果**。

### 原 submission 实例（官方院子桥式通道）

```
此类病害对结构安全暂时不会带来安全隐患，在长期作用下对结构耐久性有一定影响；官方院子桥式
通道于2014年12月进行了外观检查、技术状况等级评定及安全性评估，为更详细了解桥梁在运营过程
中病害的发展状况，……
```

### 问题清单

| # | 问题 | 说明 |
|---|---|---|
| 1 | "此类病害对结构安全暂时不会带来安全隐患"是**总体安全评估结论** | 应放在 safety_impact，不是 risk_points |
| 2 | "2014年12月进行了外观检查、技术状况等级评定…"是**历史检测过程说明** | 与风险点无关 |
| 3 | **没有任何病害事实**（哪个构件、什么病害） | 官方每条必须"病害+后果"成对 |
| 4 | 太平水库版是**病害+尺寸清单**（"裂缝，L=1.0m，W=0.02mm…均未超过最大允许裂缝宽度"） | 缺后果部分；且"未超过允许值"是评估句 |

## 提分点 6：P0 段评分段句式（详细结论段 1）

### 官方期望（赛题一文档详细结论段 1）

```
经综合评定，该桥总体技术状况评分 78.5 分，总体技术状况等级为 C级。其中，上部结构评分
82.3 分（B级），下部结构评分 76.8 分（C级），桥面系评分 71.2 分（C级）。
```

要素：`该桥` + `评分在前、等级在后` + `。其中，` + `评分 X 分（X级）`。

### 原 submission 实例（华陶跨线桥）


### 问题清单

| # | 问题 | 对照 |
|---|---|---|
| 1 | **等级在前、评分在后**（"等级为B级，评分为87.93分"） | 官方"评分 78.5 分，等级为 C级" |
| 2 | **称谓用全称**（"华陶跨线桥（K42+350）"） | 官方"该桥" |
| 3 | 缺少"**。其中，**"衔接 | 官方句号+"其中，" |
