# 赛题任务定义

## 直接评测对象

当前任务不是首先回答在线自然语言问题，而是批量完成：

```text
原始定检报告 → 固定模板信息提取报告
```

提交产物是 Word 文档，目标文档包含概要表、详细结论、建议明细、病害列表、病害成因、处置建议和安全影响。

## 结果导向流水线

1. `.doc` 转换为 `.docx`，必要时同时生成 PDF 页面兜底。
2. 原生 Word 段落、标题、表格、单元格和图片关系解析。
3. 按章节路由到评分、病害、建议、安全评估和结论抽取器。
4. 先形成带来源的结构化事实，再生成长文本。
5. 对数字、等级、行数、字段完整性和证据引用做校验。
6. 用固定模板渲染 `.docx`，并进行可打开性和命名检查。

## 迁移边界

旧 RAG 项目中的 Parser 接口、规范中间结构、Processing Profile、轻量模型适配、证据定位、阶段化 Workflow 和评测思想可以复用。

Milvus、Neo4j、多租户、企业权限、复杂任务引擎和在线问答 UI 不属于当前第一阶段主线。RAG 只在需要跨报告检索原文或辅助证据融合时作为局部能力接入。
