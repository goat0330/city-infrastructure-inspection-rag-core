# 标签口径记录

本文件记录从当前训练标签样例中观察到的口径，不把少量样例观察冒充为全量标注规则。正式建模前需要对全部可解析标签做统计审计。

## 当前已观察事项

- 标签不是原始报告的简单摘要，而是固定模板下的字段化报告。
- 同一病害序号可能包含多个具体位置描述；内部记录必须保留为多条观察，渲染时再按模板合并单元格。
- 病害列表、建议明细、评分和等级是确定性抽取的优先目标。
- 当前可见建议类别包括“立即维修、立即处置、尽快维修、预防性养护”；类别推断只在主预测链中显式开启，并通过质量标记区分原文类别与推断类别。
- “无对比年度”报告会出现上一次评分、上一次等级、病害发展趋势和历史状态为空/无的固定表达。
- 训练标签中的报告日期可能与原报告正文的日期表达不同，不能只按字面定义强行改写。

## 待全量统计确认

| 字段 | 需要确认的候选口径 |
| --- | --- |
| 报告日期 | 封面年月、报告出具日期或标签制作年月 |
| 病害部位 | 结构大类、构件、方向/跨号/具体位置的粒度 |
| 是否新增 | 首次检测和无历史对比时的固定值 |
| 建议类别 | 立即维修、立即处置、尽快维修、预防性养护的映射规则；推断规则需保留审计标记 |
| 总体结论 | 原文摘录、压缩改写或事实驱动生成 |

在这些规则冻结前，不建议直接进行端到端微调；应先建立字段级基线和冲突清单。
